# Lights Out

A Lights Out puzzle game built with **C# + Avalonia UI**, published with **NativeAOT**
for Windows, Linux and macOS, backed by a small **C solver library**
(`lightsout.dll` / `liblightsout.so` / `liblightsout.dylib`).

The board is drawn with Avalonia primitives, so the app has no runtime XAML reflection
and stays trim/AOT friendly. All puzzles are generated by clicking a random set of cells
on a dark board, which means every start position is solvable.

## Features

- Any board size from 2x2 up to 40x40 (`Game -> New game`, or `Custom size...`).
- Dark theme, rounded cells, hover outline, status bar with move counter.
- **Solve -> New board (blank)**: an empty board in edit mode where a click lights up
  only that cell, so any position can be entered by hand.
- **Solve -> Solve (any)**: a quick solution that clears the board but is not necessarily
  the fewest presses; the marked cells are drawn with a ring.
- **Solve -> Solve minimum**: the fewest presses that clear the board.
- **Solve -> Clear marks** removes the rings - they are not cleared by clicking the board.
- Keyboard: `N` new game, `R` restart, `B` blank board, `S` solve (any), `M` solve minimum,
  `C` clear marks, `Esc` quit.

## Solver

`native/lightsout.c` is a dependency-free C99 solver with two engines:

1. **First-row enumeration** for boards whose short side is at most 26. Clicking row 0
   fully determines the rest of the board, so enumerating all `2^W` first-row patterns
   covers the whole solution space and the fewest-presses answer is exact.
2. **Bit-packed GF(2) Gauss-Jordan** for larger boards, with a nullspace sweep when it is
   small enough.

```c
int los_solve(int rows, int cols, const unsigned char *cells,
              int want_min, unsigned char *clicks, int *count);
```

`cells` and `clicks` are row-major `rows * cols` bytes (1 = lit / press). Returns
`1` solved, `0` unsolvable, `-1` too large, `-2` bad arguments or out of memory.
The library keeps reusable buffers and is therefore not thread safe.

The same source also ships a `selftest` target that solves random boards for many shapes
and applies the returned presses to verify the board really goes dark.

## Layout

```
native/       C solver library (lightsout.h, lightsout.c, selftest.c, CMakeLists.txt)
src/LightsOut Avalonia app (C#, NativeAOT)
.github/      CI: builds the library, the app, and publishes tagged releases
```

## Building

Everything is built on GitHub Actions; no local toolchain is required.

```bash
cmake -S native -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native -j
./build/native/selftest

dotnet publish src/LightsOut/LightsOut.csproj -c Release -r linux-x64 -o dist/linux-x64
cp build/native/liblightsout.so dist/linux-x64/
```

On Windows the library lands in `build/native/Release/lightsout.dll` and the app is
published with `-r win-x64`.

## Releases

Tagged builds (`v*`) produce `lightsout-1.0.0-win-x64.zip`,
`lightsout-1.0.0-linux-x64.zip`, `lightsout-1.0.0-osx-arm64.zip` and
`lightsout-1.0.0-osx-x64.zip`, each containing the self-contained native executable
and the matching solver library next to it (`lightsout.dll`, `liblightsout.so` or
`liblightsout.dylib`).
